## Purpose

This bounded addendum defines the A6 Composition Transition Predicate (A6-CTP) for EXIT, SPLIT, HOLD, and DISSOLVE classification under governed binding. Its core threshold is unique lawful continuation: EXIT requires exactly one lawful successor; SPLIT requires resolved incompatible successor claims; HOLD preserves unresolved classification state; DISSOLVE requires witnessed successor-space exhaustion.
