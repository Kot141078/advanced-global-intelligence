# Release Notes - v0.1.1-recovery.5

## Purpose of Recovery Build 5

Recovery Build 5 corrects the publication surface of Recovery Build 4. The negative-only
architecture, F0 gate result, fixture counts, and external closure requirements are not
intentionally broadened.

## Public-release corrections

- replaced the prior Russian README with an English `README.md`;
- removed Zenodo deposition instructions from the scientific package;
- removed internal cold-review files, author decision sheets, review receipts, and recovery
  working provenance from the public package;
- removed the superseded v0.1 historical archive from the public package;
- removed administrative PDF renderings of the README, license, release notes, and deposit
  instructions;
- replaced the former multi-file rendering dump with two publication PDFs: a primary academic
  volume and a canonical-inventory supplement;
- added title pages, author name, ORCID, affiliation, abstract, keywords, publication status,
  chapter dividers, page numbering, PDF metadata, and bookmarks;
- retained the English UTF-8 Markdown and JSON sources as the machine-readable record;
- updated public artifact aliases in the F0 Acceptance Evidence Matrix so no active source
  points to excluded internal-review material;
- regenerated publication metadata, manifest, and checksums.
