| Surface | License |
| --- | --- |
| Code, tests, software freeze files, and software examples included in the Zenodo archive | AGPL-3.0-only |
| Accepted PDFs, Markdown companions, metadata, manifests, selected audit reports, README, NOTICE, CITATION, and non-code documentation | CC-BY-4.0 |

The source-intake ZIP in the Zenodo archive is a provenance artifact. It may contain earlier staging text. The final public package license scope is defined by the root license files and metadata in the Zenodo package and by this bridge record.

This metadata bridge does not replace the Zenodo archive and does not create a competing package.
