# Research

This directory contains public research artifacts that are intentionally **not** placed in canonical or DOI-immutable package trees.

Every subdirectory must state:

- its relationship to controlling publications;
- whether it has normative weight;
- whether it supplies closure, conformance, implementation, or deployment evidence;
- its file and citation authority;
- its package-specific rights.
