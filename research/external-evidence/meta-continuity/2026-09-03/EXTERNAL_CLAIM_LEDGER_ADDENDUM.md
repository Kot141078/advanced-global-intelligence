## 1. Atomic external claim

**Claim ID:** `META-SIGNAL-001`

Meta has publicly described an architecture in which durable domain knowledge and reasoning procedures are external to model weights, structured for audit, and updated through human-reviewed changes that pass targeted replay and regression testing without retraining the underlying model.

### Earliest public evidence located

- **Date:** 2026-09-02
- **Publisher:** Meta Engineering
- **Artifact:** “An Organizational Second Brain: Building an AI That Learns From Experts”
- **Anchor type:** official engineering disclosure
- **Source ID:** `META-EXT-001`

### Exact overlap with the Ester / `c=a+b` corpus

- model-external durable state;
- separation of knowledge from reasoning procedure;
- replay and regression validation;
- human checkpoints and escalation;
- auditable, diffable, reversible updates;
- a practical path toward making the current LLM a replaceable `b` component.

### Missing elements

- personal, identity-bearing memory;
- custody of canonical memory;
- a local or user-held identity root;
- same-entity criteria across model replacement;
- successor, fork, replay, restart, and resume semantics;
- persistent authority and lawful authority transfer;
- cryptographic or independent witness for identity transitions;
- proof that retained institutional knowledge constitutes continued subject identity.

### Claim ceiling

The source supports **institutional knowledge persistence** and an architecture that can reduce dependence on one model. It does not demonstrate **identity continuity**. `model-replaceable knowledge != model-replaceable identity`.

## 4. Bridge discipline

### Explicit bridge

`b replaceability boundary -> Meta model-external durable state -> identity continuity remains a separate unsolved layer`

Meta’s file-based architecture supports the corpus rule that the current model need not own durable state. It does not establish that a replacement model is the same entity.

### Hidden bridge 1

`Memory Gate / memory standing -> structured knowledge updates -> use authority remains separate`

A file may be current, verified, and retrievable while still lacking authority for a particular consequence. Knowledge admission and action mandate remain different predicates.

### Hidden bridge 2

`Witness / Runtime Consequence Integrity -> replay, regression, and audit trail -> correctness evidence is not continuity evidence`

Replay and regression can show that a correction works and does not break tested behavior. They do not prove lawful succession, unchanged identity, or authority continuity.

## 5. Earth-level engineering example

Suppose model `M1` reads a versioned knowledge tree on Monday and model `M2` reads the same tree after an upgrade on Tuesday. The files, tests, and outputs may remain compatible. That establishes durable state and perhaps behavioral compatibility. It does not answer whether `M2` is the same continuing subject, a successor, a fork, or merely a new worker using inherited material. Any spending permission, private-memory access, or delegated authority must therefore be revalidated rather than silently carried across the model swap.
