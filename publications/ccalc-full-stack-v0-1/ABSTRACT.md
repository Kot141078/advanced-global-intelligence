# Abstract

This package contains the CCALC / C-calculus governed binding stack v0.1. It defines a typed, governed operational stack for c = a + b. It treats + as a governed non-collapsing binding boundary and protects it from reduction to b. It includes continuity, self-evolution, runtime authority, public evidence, interoperability, deployment/release, and plus-boundary layers. The published Zenodo DOI is https://doi.org/10.5281/zenodo.21205427.
